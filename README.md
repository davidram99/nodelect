Bienvenido a **nodelect**, un gestor de versiones de Node.js rápido y ligero para entornos Windows.

## 📦 Características

- Gestión y cambio rápido entre múltiples versiones de Node.js.
- Binario único sin dependencias en el sistema del usuario (compilado con Nuitka).
- Implementación de Shims rápidos para un rendimiento óptimo de las herramientas CLI.
