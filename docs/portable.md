# 🏷️ Generar Versión Portable

Este proyecto incluye un script de PowerShell para generar un archivo `.zip` que contiene la versión portable de **nodelect**. Esta versión está diseñada para poder usarse y distribuirse sin necesidad de instalación en el sistema.

## 🚀 Generando el archivo `.zip`

Para generar la versión portable en formato `.zip`, simplemente abre una terminal o consola de PowerShell en la raíz del proyecto y ejecuta el siguiente script:

```powershell
.\portable\portable_build.ps1
```

El script se encargará de realizar las tareas de empaquetado y cuando finalice tendrás un archivo preparado para ser utilizado en cualquier equipo Windows.
